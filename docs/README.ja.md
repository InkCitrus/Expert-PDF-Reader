# Expert PDF Reader

[English](../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · **日本語** · [한국어](README.ko.md)

読むことに特化した macOS ネイティブの PDF リーダーです。タブ、分割表示、GPU で描画する昼 / セピア / 夜のページテーマを備えています。インターフェイスは PDF Expert 3 を参考にしていますが、編集・注釈・サブスクリプションはありません。

---

## ✨ 主な機能

- **読書テーマ**
  - **昼**：元の色のまま表示。キャンバス背景は `#DCDCDE` / `#131314`。
  - **セピア**：温かみのある用紙 `#F5EFDC`、インク `#3F2A18`、キャンバス背景 `#E5DECF`。色は色相を保つので、図やハイライトも見分けられます。
  - **夜**：明るさだけを反転し色相を保つ、やわらかな反転表示（$`L' = 0.75(1 - L)`$）。用紙 `#000000`、インク `#BFBFBF` で暗い場所でもまぶしくなく、カラーの図も見分けられます。キャンバス背景は `#202223`。
  - **システムに合わせる**：システムの外観に合わせて昼と夜を切り替えます。ライトモードでは昼の代わりにセピアを使うこともできます。
  - どの拡大率でもページはくっきり：カラーマトリクスを `NSClipView` の拡大処理より上で適用するため、PDFKit のタイルはフル Retina 解像度で描画されます。
- **12 言語**：**简体中文**、**繁體中文**、**English**、**日本語**、**한국어**、**Français**、**Deutsch**、**Español**、**Italiano**、**Português**、**Русский**、**Українська** に対応し、「システムに合わせる」も選べます。「設定」（`⌘,`）や「表示」メニューからその場で切り替えられます。内蔵の「読書ガイド」PDF も各言語に対応しています。
- **インターフェイス**
  - **標準タイトルバーと 40pt のタブバー**：標準のウインドウボタンをタブの上に配置し、アイコンだけのホームタブ、書類タブ（ホバーで閉じるボタンを表示、コンテキストメニュー対応）、ファイルを開く `+` ボタンを並べます。
  - **ツールバー**：「書類の概要」「ページ一覧」「表示設定」の切り替えボタン、プリセット付きのズームポップアップと `−` / `+`、テーマの切り替え、余白のトリミング、回転、共有、ブックマーク、検索フィールド。
  - **左ドック（240pt）**：「サムネイル」「アウトライン」（読んでいるセクションをハイライト）「ブックマーク」を切り替えるか、「表示設定」パネル（ページレイアウト、分割表示、読書テーマ、余白のトリミング、回転、外観モード）を表示します。
  - **右側の検索ドック**、右下の**ページカウンター**（クリックまたは `⌥⌘G` で「ページへ移動」）、**ページ一覧**グリッド（`⌃⌘1`）。
  - タブバー・ツールバー・パネルは「**システムに合わせる / ライト / ダーク**」の外観モードに従います。
- **ホームタブ**：「ホーム」「最近の項目」「お気に入り」（さらに「ファイルを開く…」「ショートカットとヒント」「読書ガイド」「設定」。「ヘルプ」›「読書ガイド」（`⌘?`）でどこからでもガイドを開けます）を並べたサイドバー、ドラッグ＆ドロップ領域、読書テーマのカード、ワンクリックでショートカット一覧を開ける**クイックヒント**、ロケールに応じた日付を表示する書類グリッド。
- **ショートカットとヒント（`⌘/`）**：いつでも `⌘/`、タブバー右側の `?` ボタン、または「ヘルプ」›「ショートカットとヒント」から、実機キーキャップ風の速記パネルを表示できます。インクリメンタル検索とカテゴリ分類（*すべて*、*タブ*、*読書とナビゲーション*、*表示と拡大縮小*、*検索とブックマーク*、*便利なヒント*）に対応しています。
- **タブとウインドウ**：
  - **ブラウザ感覚のマルチウインドウ**：タブをタブバーの外へ下にドラッグして独立したウインドウに分離。ウインドウ間でタブをドラッグして結合、または「ウインドウ」›「すべてのウインドウを結合」でまとめられます。
  - **Dock と新規ウインドウ（`⌘N`）**：Dock アイコンを右クリックして「新規ウインドウ」「開く…」「最近使った項目を開く」を選択できます。
  - **快適なタブ管理**：左右ドラッグでタブの並び替え、標準ツールチップで完全なファイルパスを表示、2 つ以上の書類を開いているときは「すべてのタブ」メニュー（`⌄`）を利用可能。同名のファイルは親フォルダ名で自動識別されます。
  - **ショートカット操作**：`⌃⇥` / `⌃⇧⇥`（または `⌥⌘←` / `⌥⌘→`、`⇧⌘]` / `⇧⌘[`、`⌃PageUp` / `⌃PageDown`）でタブを素早く切り替え；`⌃1…9` または `⌥⌘1…9` で第 1〜8 タブや最後のタブ（9）へダイレクトに移動；`⇧⌘T` で閉じたタブ（最大 25 件）を元の位置と読書位置を保ったまま復元できます。
  - **Mission Control**：ウインドウタイトルと代表ファイルアイコンが現在閲覧中の書類名とリアルタイムに同期し、Mission Control、App Exposé、ステージマネージャ、Dock でひと目で判別できます。
  - **分割表示**：「左右に分割」または「上下に分割」で表示でき、「左右を入れ替え」と「スクロールと拡大縮小を同期」に対応。比較するもう一方の書類はホームタブから選べます。
- **閲覧機能**
  - 「単一ページ」`⌘1`、「見開き」`⌘2`、「見開き（表紙を単独表示）」`⌘3`。見開きの 2 ページはノドでぴったり合わさります。右綴じの本は自動で判別し（PDF の指定、または縦書きページのノンブルの位置から）、右から左へめくります。「表示」›「ページの方向」で変更できます。
  - **ページの文字認識（`⌥⌘C`）**：「編集」›「このページの文字を認識してコピー」で現在のページを必要に応じて読み取ります。中国語の縦書き（上から下、右の列から左の列）に対応し、通常のコピーでは中国語の余分な空白を除去し、段落と英単語の空白を保持します。
  - **本のページ番号**：ページカウンターと「ページへ移動」は本に印刷されたノンブルを使います（PDF のページラベルがない、または誤っているときはページから読み取ります）。見開きでは 2 ページ分を表示します。前付けのローマ数字と本文のアラビア数字のノンブルも判別し、目次とサムネールにも同じ番号を表示します。「ページへ移動」で `(n)` と入力するとファイルの n ページ目へ移動します。
  - **`←` / `→`**：フォーカスのあるペインでページをめくります。
  - **余白をトリミング（`⇧⌘M`）**：各ページの内容の範囲を検出して余白を切り詰めます。計算はバックグラウンドで行います。
  - **左サイドバー（`⌘B`）**：テーマを反映したページのサムネイル、書類のアウトライン、ブックマーク（`⌘D`）。
  - **全文検索（`⌘F`）**：バックグラウンドで実行し、見つかったそばからページごとに結果を一覧表示します。前後の文脈はハイライト付きです。
  - **前回の続きから**：どの書類も前回のページ・拡大率・レイアウトで開き直し、起動時には前回のセッションのタブを復元します。
  - **パスワードで保護された PDF** はパスワードの入力を求めます。開けないファイルは、その理由を表示します。
  - PDF はウインドウのどこにでも、または Dock のアイコンにドロップして開けます。`⌘+` に加えて `⌘=` でも拡大できます。
- **高速なホームタブ**：「最近の項目」には最大 50 件の書類を保持し（直近の 10 件は「ファイル」›「最近使った項目を開く」にも表示）、表紙のサムネイルはバックグラウンドで読み込んでディスクにキャッシュします。移動や名前の変更をしたファイルも、ブックマークと読書位置ごと「最近の項目」/「お気に入り」に残り、削除したりゴミ箱に入れたりしたファイルは自動的に取り除かれます。
- **オリジナルのアプリアイコン**：角を折ったページが対角線に沿って昼 → セピア → 夜と移り変わるデザインで、`scripts/make_app_icon.swift` がコードで描画します。

## 📦 インストール

[Releases](https://github.com/InkCitrus/Expert-PDF-Reader/releases) から `Expert-PDF-Reader-<version>.dmg` をダウンロードして開き、**Expert PDF Reader** を「**アプリケーション**」フォルダにドラッグします。macOS 14 以降（Apple シリコンまたは Intel）が必要です。

リリースビルドはまだ Apple の公証を受けていないため、初回起動は macOS にブロックされます。「**システム設定 › プライバシーとセキュリティ**」を開いて「**このまま開く**」をクリックするか、次のコマンドを実行してください：

```zsh
xattr -dr com.apple.quarantine "/Applications/Expert PDF Reader.app"
```

## 🛠 ビルドと実行

Xcode Command Line Tools（`xcode-select --install`）が必要です。リポジトリのルートで実行します：

```zsh
./build.sh && open "build/Expert PDF Reader.app"
```

`build.sh` は既定で `xcrun` が選択する macOS SDK を使ってビルドします。macOS 27 SDK の SwiftUI には、Xcode には付属するものの Command Line Tools には含まれないコンパイラプラグイン（SwiftUIMacros）が必要です。そのため Xcode がない環境では、`build.sh` はインストール済みの SDK のうち使える最新のものに切り替え、使用した SDK を表示します。SDK を自分で指定するには `SDK_PATH` を設定します：

```zsh
SDK_PATH=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk ./build.sh
```

ユニバーサル（Apple シリコン + Intel）版をビルドして `.dmg` にパッケージする場合：

```zsh
ARCHS="arm64 x86_64" ./build.sh && ./scripts/make_dmg.sh
```

リリースを公開するには、`v*` タグをプッシュする（`git tag v0.1.0 && git push origin v0.1.0`）、GitHub で新しい `v*` タグを付けてリリースを公開する、Actions タブからバージョン番号を指定して **Release** ワークフローを実行する、のいずれかを行います。その後 `.github/workflows/release.yml` が `.dmg` をビルドし、GitHub Release に添付します。また、プルリクエストごと、および `main` へのプッシュごとに、CI が `.dmg` をビルドして成果物として保存します。

アイコンのデザインを変更したら、アプリアイコン（`Assets/AppIcon.icns` + `Assets/AppIcon.png`）を再生成します：

```zsh
swift scripts/make_app_icon.swift
```
