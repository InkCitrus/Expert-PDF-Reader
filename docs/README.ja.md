# Expert PDF Reader (`OpenPDFExpert`)

[English](../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · **日本語** · [한국어](README.ko.md)

**PDF Expert (v3.13.4) Reader Edition**（閲覧専用版）を macOS ネイティブでクリーンルーム実装したアプリです。[`morluto/rea`](https://github.com/morluto/rea) のリバースエンジニアリング手法（`Decompile → Understand → Recreate`：逆コンパイル → 理解 → 再構築）に沿って開発しています。

中核となる **PDF の閲覧とテーマ切り替え**の体験だけを残し、編集・注釈・ペイウォールといった余計な機能は省いています。

---

## ✨ 主な機能

- **GPU で 1:1 再現したページ閲覧テーマ（`RDPDFShaders.metallib`）**
  - **Day（日间）**：元の色をくっきり表示（用紙 `#FFFFFF`、キャンバス背景 `#DCDCDE` / `#131314`）。
  - **Sepia（纸质）**：`sepiaTexturingModeFragmentShader` のアフィン色変換行列を正確に再現（温かみのあるクリーム色の用紙 `#F5EFDC`、エスプレッソ色のインク `#3F2A18`、キャンバス背景 `#E5DECF`）。
  - **Night（夜间）**：`nightTexturingModeFragmentShader` の輝度反転を正確に再現（$v = 0.75 - 0.25(R+G+B)$、用紙 `#000000`、暗い部屋でのまぶしさを抑える輝度 75% の柔らかなシルバーのインク `#BFBFBF`、キャンバス背景 `#202223`）。
  - **`PDFPageLayer` サブレイヤー単位の精密なフィルタ**：タイルのコンテンツレイヤー（`sublayers[2].sublayers[0]`）と用紙レイヤー（`sublayers[3]`）だけにフィルタをかけ、自然なドロップシャドウ（`sublayers[0..1]`）とテキスト選択のハイライト（`sublayers[2].sublayers[1]`）はそのまま残します。
- **PDF Expert 3 風のインターフェイス**
  - **一体化した 40pt のタイトルバー**：ウインドウの信号機ボタンをタブバーの縦中央に配置し、アイコンだけのホームタブ（`HomeTabButtonView`）、ドキュメントタブ（ホバーで閉じるボタンを表示、コンテキストメニュー対応）、ファイルを開く `+` ボタンを並べます。
  - **ツールバー**：ドキュメント概要 / ページ一覧 / 表示設定の切り替えボタン、プリセット付きのズームポップアップと `−`/`+`、Day / Sepia / Night の切り替え、余白の除去、回転、共有、ブックマーク、検索フィールド。
  - **左ドック（240pt）**：アイコンのセグメントでサムネイル / アウトライン（読んでいるセクションをハイライト）/ ブックマークを切り替えるか、表示設定パネル（ページレイアウト、分割表示、閲覧テーマ、余白の除去、回転、外観）を表示します。
  - **右側の検索ドック**、右下の**ページカウンター**（クリックで「ページへ移動」）、**ページ一覧**グリッド（`⌃⌘1`）。
  - 常にグラファイト色の PDF Expert のウインドウ枠とは異なり、タブバー・ツールバー・パネルは **システム**（跟随系统）/ **ライト**（浅色）/ **ダーク**（深色）の外観設定に従います（`RDDesignLibrary` のライト / ダーク用トークンペアを使用）。
- **ホームタブ（`HomeTab.framework` アーキテクチャ）**
  - 不透明な `216pt` サイドバー：`主页`（ホーム）、`最近打开`（最近使った項目）、`收藏夹`（お気に入り）に加えて、`打开文件…`（ファイルを開く…）、`阅读指南`（閲覧ガイド）、`设置`（設定）。ほかに破線のドラッグ＆ドロップ領域、閲覧テーマのカード、最近使った項目 / お気に入りのグリッド（`清除全部 · 查看全部`：すべて消去 · すべて表示）、シンボリックリンクを正規化した `DocumentID`、ロケールに応じたタイムスタンプ表示。
- **マルチタブと分割表示での比較（`PDFDocumentsSplitViewController`）**
  - 縦分割（左右）と横分割（上下）の分割表示、表示位置の入れ替え、スクロールとズームの同期、比較用のもう一方のドキュメントを選べる HomeTab ピッカーを内蔵。
- **閲覧機能**
  - 単一ページ（`⌘1`）、見開き（`⌘2`）、表紙を単独で表示する見開き（`⌘3`）。
  - **余白の除去（`清除空白边`、`⇧⌘M`）**：インクのバウンディングボックスを自動検出し、ページの余白をトリミングします。
  - **左サイドバー（`⌘B`）**：ページのサムネイル（適用中の GPU テーマで描画）、階層型の目次（`PDFOutline`）、ブックマーク（`⌘D`）。
  - **全文検索（`⌘F`）**：キーワードを即座にハイライト。結果はページごとに、ハイライト付きの前後の文脈とともに一覧表示されます。
- **オリジナルのアプリアイコン**：角を折ったページが対角線に沿って Day → Sepia → Night と移り変わるデザインで、`scripts/make_app_icon.swift` がコードで描画します。

## 🛠 ビルドと実行

リポジトリのルートで実行します：

```zsh
./build.sh && open OpenPDFExpert.app
```

アイコンのデザインを変更したら、アプリアイコン（`Assets/AppIcon.icns` + `Assets/AppIcon.png`）を再生成します：

```zsh
swift scripts/make_app_icon.swift
```
