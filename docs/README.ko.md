# Expert PDF Reader

[English](../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · **한국어**

읽기에 집중한 macOS 네이티브 PDF 리더입니다. 탭, 분할 보기, GPU로 렌더링하는 주간 / 세피아 / 야간 페이지 테마를 제공합니다. 인터페이스는 PDF Expert 3에서 영감을 받았지만 편집, 주석, 구독은 없습니다.

---

## ✨ 주요 기능

- **읽기 테마**
  - **주간**: 원본 색상 그대로이며, 캔버스 배경은 `#DCDCDE` / `#131314`입니다.
  - **세피아**: 따뜻한 용지 `#F5EFDC`, 잉크 `#3F2A18`, 캔버스 배경 `#E5DECF`. 색은 색조를 유지해 그림과 하이라이트도 구별됩니다.
  - **야간**: 밝기만 반전하고 색조는 유지하는 부드러운 반전($`L' = 0.75(1 - L)`$). 용지 `#000000`, 잉크 `#BFBFBF`로 어두운 곳에서도 눈부시지 않고 컬러 그림도 알아볼 수 있으며, 캔버스 배경은 `#202223`입니다.
  - **시스템 설정 따르기**: 시스템 화면 모드에 따라 주간과 야간을 전환하며, 라이트 모드에서 주간 대신 세피아를 쓰도록 설정할 수도 있습니다.
  - 어떤 배율에서도 페이지가 선명합니다. 색상 행렬을 `NSClipView`의 확대 변환 위에서 적용하므로 PDFKit 타일이 Retina 전체 해상도로 렌더링됩니다.
- **12개 언어**: **简体中文**, **繁體中文**, **English**, **日本語**, **한국어**, **Français**, **Deutsch**, **Español**, **Italiano**, **Português**, **Русский**, **Українська**를 지원하며 '시스템 설정 따르기'도 선택할 수 있습니다. '설정'(`⌘,`)이나 '보기' 메뉴에서 바로 전환할 수 있고, 내장된 '읽기 가이드' PDF도 현지화되어 있습니다.
- **인터페이스**
  - **통합 제목 표시줄**: 기본 창 버튼과 탭을 같은 줄에 표시합니다. 홈, 문서 탭, 파일을 여는 `+` 버튼이 있습니다.
  - **툴바**: '문서 요약' / '페이지 개요' / '보기 옵션' 토글, 프리셋과 `−` / `+` 버튼이 있는 확대/축소 팝업, 테마 전환기, 여백 제거, 회전, 공유, 책갈피, 검색 필드.
  - **통합 제목 표시줄**: 기본 창 버튼과 탭을 같은 줄에 표시합니다. 홈, 문서 탭, 파일을 여는 `+` 버튼이 있습니다.
  - **오른쪽 검색 독**, 오른쪽 아래 **페이지 카운터**(클릭하거나 `⌥⌘G`를 누르면 '페이지로 이동'), **페이지 개요** 그리드(`⌃⌘1`).
  - 탭 바·툴바·패널이 **시스템 설정 따르기 / 라이트 / 다크** 화면 모드를 따릅니다.
- **홈 탭**: '홈', '최근 항목', '즐겨찾기'(그리고 '파일 열기…', '단축키 및 팁', '읽기 가이드', '설정'. '도움말' › '읽기 가이드'(`⌘?`)로 어디서든 가이드를 열 수 있음)가 있는 사이드바, 드래그 앤 드롭 영역, 읽기 테마 카드, 클릭 한 번으로 단축키 안내를 여는 **빠른 시작 팁**, 로케일에 맞춘 날짜를 표시하는 문서 그리드.
- **단축키 및 팁 가이드(`⌘/`)**: 언제든지 `⌘/`, 탭 막대 오른쪽의 `?` 버튼, 또는 '도움말' › '단축키 및 팁'을 눌러 실제 키캡 스타일의 단축키 패널을 열 수 있습니다. 실시간 검색 및 카테고리 필터(*전체*, *탭*, *읽기 및 탐색*, *보기 및 확대/축소*, *검색 및 책갈피*, *유용한 팁*)를 지원합니다.
- **탭과 윈도우**:
  - **웹 브라우저 스타일 멀티 윈도우**: 탭을 탭 막대 아래로 드래그하여 독립된 윈도우로 분리할 수 있습니다. 윈도우 간 탭을 드래그하여 합치거나 '윈도우' › '모든 윈도우 통합'을 선택할 수 있습니다.
  - **Dock 및 새로운 윈도우(`⌘N`)**: Dock 아이콘을 마우스 오른쪽 버튼으로 클릭하여 '새로운 윈도우', '열기…', '최근 사용 항목 열기'를 선택할 수 있습니다.
  - **편리한 탭 관리**: 좌우 드래그로 탭 순서 변경, 기본 도구 설명으로 전체 파일 경로 표시, 문서가 2개 이상일 때 '모든 탭' 메뉴(`⌄`) 제공. 서로 다른 폴더의 동일한 파일 이름은 상위 폴더 이름으로 자동 구분됩니다.
  - **탭 단축키**: `⌃⇥` / `⌃⇧⇥`로 문서 탭을 순환하며 홈은 건너뜁니다. `⇧⌘T`로 닫은 탭과 읽던 위치를 복원합니다.
  - **미션 컨트롤(Mission Control)**: 윈도우 제목과 대표 파일 아이콘이 현재 읽고 있는 문서 이름과 실시간으로 동기화되어 Mission Control, App Exposé, 스테이지 매니저, Dock에서 쉽게 확인할 수 있습니다.
  - **분할 보기**: '수직 분할(좌/우)' 또는 '수평 분할(상/하)'로 나눠 보고, '위치 바꾸기'와 '스크롤 및 확대/축소 동기화'를 지원하며, 홈 탭에서 비교할 두 번째 문서를 고를 수 있습니다.
- **읽기 기능**
  - '단일 페이지' `⌘1`, '두 페이지' `⌘2`, '두 페이지(표지 단독 표시)' `⌘3`. 펼친 두 페이지는 책등에서 맞붙습니다. 오른쪽으로 제본된 책은 자동으로 인식해(PDF의 지정이나 세로쓰기 페이지의 쪽 번호 위치로) 오른쪽에서 왼쪽으로 넘기며, '보기' › '페이지 방향'에서 바꿀 수 있습니다.
  - **스캔 문서의 텍스트 선택**: 로컬 OCR의 문자 좌표를 사용해 텍스트를 선택합니다. 중국어 번체와 세로쓰기도 지원하며, 드래그로 선택한 뒤 `⌘C`로 복사할 수 있습니다. 선택할 때만 인식하고 원본 PDF는 수정하지 않습니다.
  - **책의 쪽 번호**: 페이지 카운터와 '페이지로 이동'은 책에 인쇄된 쪽 번호를 사용하고(PDF의 페이지 레이블이 없거나 틀리면 페이지에서 읽어 냅니다), 두 페이지 보기에서는 두 쪽 번호를 함께 표시합니다. 머리말의 로마 숫자와 본문의 아라비아 숫자 쪽 번호도 인식하며, 목차와 축소판에도 같은 번호를 표시합니다. '페이지로 이동'에 `(n)`을 입력하면 파일의 n번째 페이지로 이동합니다.
  - **`←` / `→`**: 포커스가 있는 분할 영역에서 페이지를 넘깁니다.
  - **여백 제거(`⇧⌘M`)**: 각 페이지의 콘텐츠 경계를 감지해 여백을 잘라내며, 계산은 백그라운드에서 이루어집니다.
  - **왼쪽 사이드바(`⌘B`)**: 테마가 적용된 페이지 축소판, 문서 개요, 책갈피(`⌘D`).
  - **전체 텍스트 검색(`⌘F`)**: 백그라운드에서 실행되며, 찾는 대로 결과를 페이지별로 보여 주고 앞뒤 문맥을 하이라이트합니다.
  - **마지막으로 읽던 곳부터**: 모든 문서가 마지막 페이지·확대/축소·레이아웃 그대로 다시 열리고, 실행할 때 지난 세션의 탭을 복원합니다.
  - **암호로 보호된 PDF**는 암호를 묻고, 열 수 없는 파일은 그 이유를 알려 줍니다.
  - PDF를 창의 아무 곳이나 Dock 아이콘에 놓아 열 수 있습니다. `⌘+`뿐 아니라 `⌘=`로도 확대됩니다.
- **빠른 홈 탭**: '최근 항목'에 문서를 최대 50개까지 보관하고(최근 10개는 '파일' › '최근 사용 항목 열기'에도 표시), 표지 축소판은 백그라운드에서 불러와 디스크에 캐시합니다. 이동하거나 이름을 바꾼 파일도 책갈피, 읽던 위치와 함께 '최근 항목' / '즐겨찾기'에 그대로 남고, 삭제하거나 휴지통으로 옮긴 파일은 자동으로 사라집니다.
- **오리지널 앱 아이콘**: 모서리가 접힌 페이지가 대각선을 따라 주간 → 세피아 → 야간으로 바뀌는 디자인으로, `scripts/make_app_icon.swift`가 코드로 그립니다.

## 📦 설치

[Releases](https://github.com/InkCitrus/Expert-PDF-Reader/releases)에서 `Expert-PDF-Reader-<version>.dmg`를 내려받아 열고, **Expert PDF Reader**를 **응용 프로그램** 폴더로 드래그합니다. macOS 14 이상(Apple 실리콘 또는 Intel)이 필요합니다.

릴리스 빌드는 아직 Apple의 공증을 받지 않아 macOS가 첫 실행을 차단합니다. **시스템 설정 › 개인정보 보호 및 보안**을 열고 **확인 없이 열기**를 클릭하거나, 다음을 실행하세요.

```zsh
xattr -dr com.apple.quarantine "/Applications/Expert PDF Reader.app"
```

## 🛠 빌드 및 실행

Xcode Command Line Tools(`xcode-select --install`)가 필요합니다. 저장소 루트에서 실행합니다.

```zsh
./build.sh && open "build/Expert PDF Reader.app"
```

`build.sh`는 기본적으로 `xcrun`이 선택한 macOS SDK로 빌드합니다. macOS 27 SDK의 SwiftUI에는 Xcode에는 포함되어 있지만 Command Line Tools에는 없는 컴파일러 플러그인(SwiftUIMacros)이 필요합니다. 그래서 Xcode가 없으면 `build.sh`는 설치된 SDK 중 사용할 수 있는 최신 SDK로 대신 빌드하고, 사용한 SDK를 알려 줍니다. SDK를 직접 지정하려면 `SDK_PATH`를 설정합니다.

```zsh
SDK_PATH=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk ./build.sh
```

유니버설(Apple 실리콘 + Intel) 앱을 빌드하고 `.dmg`로 패키징하려면:

```zsh
ARCHS="arm64 x86_64" ./build.sh && ./scripts/make_dmg.sh
```

릴리스를 게시하려면 `v*` 태그를 푸시하거나(`git tag v0.1.0 && git push origin v0.1.0`), GitHub에서 새 `v*` 태그로 릴리스를 게시하거나, Actions 탭에서 버전 번호를 입력해 **Release** 워크플로를 실행합니다. 그러면 `.github/workflows/release.yml`이 `.dmg`를 빌드해 GitHub Release에 첨부합니다. 또한 풀 리퀘스트마다, 그리고 `main`에 푸시할 때마다 CI가 `.dmg`를 빌드해 아티팩트로 보관합니다.

아이콘 디자인을 수정한 뒤에는 앱 아이콘(`Assets/AppIcon.icns` + `Assets/AppIcon.png`)을 다시 생성합니다.

```zsh
swift scripts/make_app_icon.swift
```
