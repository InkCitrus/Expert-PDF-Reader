# Expert PDF Reader (`OpenPDFExpert`)

[English](../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · **한국어**

**PDF Expert (v3.13.4) Reader Edition**(읽기 전용판)을 macOS 네이티브로 클린룸 구현한 앱입니다. [`morluto/rea`](https://github.com/morluto/rea)의 리버스 엔지니어링 방법론(`Decompile → Understand → Recreate`: 디컴파일 → 이해 → 재구현)을 따라 만들었습니다.

핵심인 **PDF 읽기와 테마 전환** 경험만 남기고, 편집·주석·페이월 같은 군더더기 기능은 뺐습니다.

---

## ✨ 주요 기능

- **GPU로 1:1 재현한 페이지 읽기 테마(`RDPDFShaders.metallib`)**
  - **Day(日间)**: 원본 색상을 선명하게 표시합니다(용지 `#FFFFFF`, 캔버스 배경 `#DCDCDE` / `#131314`).
  - **Sepia(纸质)**: `sepiaTexturingModeFragmentShader`의 아핀 색상 행렬을 정확히 재현합니다(따뜻한 크림색 용지 `#F5EFDC`, 에스프레소색 잉크 `#3F2A18`, 캔버스 배경 `#E5DECF`).
  - **Night(夜间)**: `nightTexturingModeFragmentShader`의 휘도 반전을 정확히 재현합니다($v = 0.75 - 0.25(R+G+B)$, 용지 `#000000`, 어두운 곳에서 눈부심을 줄이는 75% 밝기의 부드러운 은색 잉크 `#BFBFBF`, 캔버스 배경 `#202223`).
  - **정밀한 `PDFPageLayer` 하위 레이어 필터링**: 타일 콘텐츠 레이어(`sublayers[2].sublayers[0]`)와 용지 레이어(`sublayers[3]`)에만 필터를 적용하고, 자연스러운 그림자(`sublayers[0..1]`)와 텍스트 선택 하이라이트(`sublayers[2].sublayers[1]`)는 그대로 유지합니다.
- **PDF Expert 3 스타일 인터페이스**
  - **통합 40pt 타이틀 바**: 창의 신호등 버튼을 탭 바의 세로 중앙에 배치하고, 아이콘만 있는 홈 탭(`HomeTabButtonView`), 문서 탭(마우스를 올리면 닫기 버튼 표시, 컨텍스트 메뉴 지원), 파일을 여는 `+` 버튼을 제공합니다.
  - **툴바**: 문서 요약 / 페이지 개요 / 보기 설정 토글, 프리셋과 `−`/`+` 버튼이 있는 확대/축소 팝업, Day / Sepia / Night 전환기, 여백 제거, 회전, 공유, 책갈피, 검색 필드.
  - **왼쪽 독(240pt)**: 아이콘 세그먼트로 썸네일 / 목차(읽고 있는 섹션을 하이라이트) / 책갈피를 전환하거나, 보기 설정 패널(페이지 레이아웃, 화면 분할, 읽기 테마, 여백 제거, 회전, 화면 모드)을 표시합니다.
  - **오른쪽 검색 독**, 오른쪽 아래 **페이지 카운터**(클릭하면 '페이지로 이동'), **페이지 개요** 그리드(`⌃⌘1`).
  - 항상 그래파이트색인 PDF Expert의 창 테두리와 달리, 탭 바·툴바·패널이 **시스템(跟随系统) / 라이트(浅色) / 다크(深色)** 화면 모드를 따릅니다(`RDDesignLibrary`의 라이트/다크 토큰 쌍).
- **홈 탭(`HomeTab.framework` 아키텍처)**
  - 불투명한 `216pt` 사이드바: `主页`(홈), `最近打开`(최근 항목), `收藏夹`(즐겨찾기), 그리고 `打开文件…`(파일 열기…), `阅读指南`(읽기 가이드), `设置`(설정). 그 밖에 점선 드래그 앤 드롭 영역, 읽기 테마 카드, 최근 항목 / 즐겨찾기 그리드(`清除全部 · 查看全部`: 모두 지우기 · 모두 보기), 심볼릭 링크를 정규화한 `DocumentID`, 로케일에 맞춘 타임스탬프.
- **멀티 탭과 화면 분할 비교(`PDFDocumentsSplitViewController`)**
  - 세로(좌우) 및 가로(상하) 화면 분할, 위치 바꾸기, 스크롤 및 확대/축소 동기화, 비교할 두 번째 문서를 고르는 HomeTab 선택기 내장.
- **읽기 기능**
  - 단일 페이지(`⌘1`), 두 페이지(`⌘2`), 표지를 단독으로 표시하는 두 페이지(`⌘3`).
  - **여백 제거(`清除空白边`, `⇧⌘M`)**: 잉크의 경계 상자를 자동으로 감지해 페이지 여백을 잘라냅니다.
  - **왼쪽 사이드바(`⌘B`)**: 페이지 썸네일(현재 GPU 테마로 렌더링), 계층형 목차(`PDFOutline`), 책갈피(`⌘D`).
  - **전체 텍스트 검색(`⌘F`)**: 키워드를 즉시 하이라이트하고, 결과를 페이지별로 하이라이트된 앞뒤 문맥과 함께 보여 줍니다.
- **오리지널 앱 아이콘**: 모서리가 접힌 페이지가 대각선을 따라 Day → Sepia → Night로 바뀌는 디자인으로, `scripts/make_app_icon.swift`가 코드로 그립니다.

## 🛠 빌드 및 실행

저장소 루트에서 실행합니다.

```zsh
./build.sh && open OpenPDFExpert.app
```

아이콘 디자인을 수정한 뒤에는 앱 아이콘(`Assets/AppIcon.icns` + `Assets/AppIcon.png`)을 다시 생성합니다.

```zsh
swift scripts/make_app_icon.swift
```
