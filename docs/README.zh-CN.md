# Expert PDF Reader

[English](../README.md) · **简体中文** · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

一款专注阅读的 macOS 原生 PDF 阅读器：多标签页、分屏视图，以及由 GPU 渲染的日间 / 纸质 / 夜间页面主题。界面设计参考了 PDF Expert 3，但不含编辑、批注和订阅。

---

## ✨ 功能特性

- **阅读主题**
  - **日间**：原始色彩，画布背景为 `#DCDCDE` / `#131314`。
  - **纸质**：暖色纸张 `#F5EFDC`，墨迹 `#3F2A18`，画布背景 `#E5DECF`；彩色内容保留色相，图表和高亮依然分得清。
  - **夜间**：只反转亮度、保留色相的柔和反色（$`L' = 0.75(1 - L)`$），纸张 `#000000`、墨迹 `#BFBFBF`，在暗处阅读也不刺眼，彩色图表依然可辨；画布背景 `#202223`。
  - **跟随系统**：随系统外观在日间与夜间之间切换，也可以设置为浅色时用纸质代替日间。
  - 任意缩放比例下页面都保持清晰：颜色矩阵施加在 `NSClipView` 的放大变换之上，因此 PDFKit 的图块会以完整的 Retina 分辨率渲染。
- **12 种语言**：**简体中文**、**繁體中文**、**English**、**日本語**、**한국어**、**Français**、**Deutsch**、**Español**、**Italiano**、**Português**、**Русский** 和 **Українська**，也可以选择「跟随系统」；可在「设置」（`⌘,`）或「视图」菜单中实时切换。内置的「阅读指南」PDF 也已本地化。
- **界面**
  - **系统标题栏 + 40pt 标签栏**：标准窗口按钮位于标签上方；仅显示图标的主页标签、文档标签（悬停时显示关闭按钮，支持右键菜单），以及用于打开文件的 `+` 按钮。
  - **工具栏**：「文档概要」「页面概览」「显示选项」开关，带预设比例和 `−` / `+` 按钮的缩放弹出菜单，主题切换器，清除空白边、旋转、分享、书签按钮，以及搜索框。
  - **左侧面板（240pt）**：在「缩略图」「大纲」（高亮当前阅读的章节）「书签」之间切换，或显示「显示选项」面板（页面布局、分屏视图、阅读主题、清除空白边、旋转、界面外观）。
  - **右侧搜索结果面板**、右下角**页码指示器**（点击或按 `⌥⌘G` 即可「前往页码」），以及**页面概览**网格（`⌃⌘1`）。
  - 标签栏、工具栏和面板会随**跟随系统 / 浅色 / 深色**外观切换配色。
- **主页标签**：侧边栏包含「主页」「最近打开」「收藏夹」（以及「打开文件…」「快捷键与技巧」「阅读指南」「设置」；在任何地方都可以用「帮助」›「阅读指南」（`⌘?`）打开指南），还有拖放区、阅读主题卡片、支持一键跳转快捷键面板的**快速上手**卡片，以及按系统区域格式显示日期的文档网格。
- **快捷键与技巧指南（`⌘/`）**：随时按 `⌘/`、点按标签栏右侧的 `?` 按钮或「帮助」›「快捷键与技巧」，即可调出带有真实键帽质感的全键盘速查面板，支持即时搜索与分类筛选（*全部*、*标签页*、*阅读与导航*、*视图与缩放*、*搜索与书签*、*实用技巧*）。
- **标签页与多窗口**：
  - **类似浏览器的多窗口体验**：向下拖拽标签页即可分离为独立窗口；将标签拖拽到其他窗口标签栏即可合并，或选择「窗口」›「合并所有窗口」。
  - **Dock 栏与新建窗口（`⌘N`）**：右键点按 Dock 栏图标可选择「新建窗口」「打开…」与「打开最近使用」。
  - **灵活的标签管理**：左右拖拽标签调整顺序；悬停时用标准提示显示完整文件路径；打开两个以上文档时可随时展开「所有标签页」菜单（`⌄`）；同名文件自动显示父文件夹路径进行消歧。
  - **快捷键切换**：按 `⌃⇥` / `⌃⇧⇥`（或 `⌥⌘←` / `⌥⌘→`、`⇧⌘]` / `⇧⌘[`、`⌃PageUp` / `⌃PageDown`）快速切换标签；按 `⌃1…9` 或 `⌥⌘1…9` 直接跳转到第 1…8 个标签或最后一个标签（9）；`⇧⌘T` 可原位恢复最近关闭的标签（最多 25 个），保留原位置与阅读进度。
  - **调度中心（Mission Control）**：窗口标题与关联文件图标实时同步当前阅读的文件名，在调度中心、App Exposé、台前调度与程序坞中一目了然。
  - **分屏视图**：「垂直分屏（左右）」或「水平分屏（上下）」，支持「对调位置」与「同步滚动和缩放」，还可以在主页标签中挑选要对比的第二份文档。
- **阅读**
  - 「单页」`⌘1`、「双页」`⌘2`、「双页（首屏单页显示）」`⌘3`，跨页的两页在书脊处贴合。右侧装订的书会被自动识别（依据 PDF 的声明，或竖排页面上页码的位置）并从右往左翻页；可在「视图」›「翻页方向」中手动更改。
  - **页面文字识别（`⌥⌘C`）**：通过「编辑」›「识别并复制本页文字」按需读取当前页，支持从上到下、从右到左的竖排中文。普通复制会清理中文字间多余空格，保留段落与英文间距。
  - **书本页码**：页码指示器和「前往页码」使用书上印的页码（PDF 自带的页码缺失或有误时，从页面上识别），双页时显示跨页的两个页码。可识别前言的罗马数字页码与正文的阿拉伯数字页码，目录和缩略图也显示同样的页码；「前往页码」中输入 `(n)` 可跳至文件的第 n 页。
  - **`←` / `→`**：在当前聚焦的窗格中翻页。
  - **清除空白边（`⇧⌘M`）**：检测每页的内容边界并裁切页边距，计算在后台完成。
  - **左侧面板（`⌘B`）**：带主题效果的页面缩略图、文档大纲以及书签（`⌘D`）。
  - **全文搜索（`⌘F`）**：在后台运行，边搜索边按页列出结果，并高亮显示上下文。
  - **从上次离开的地方继续**：每个文档重新打开时都会回到上次的页码、缩放比例和页面布局，启动时还会恢复上次会话的标签页。
  - **受密码保护的 PDF** 会提示输入密码；无法打开的文件会说明原因。
  - 可以把 PDF 拖到窗口任意位置或程序坞图标上打开；除了 `⌘+`，`⌘=` 也能放大。
- **更快的主页标签**：「最近打开」最多保留 50 个文档（最近 10 个也会列在「文件」›「打开最近使用」中）；封面缩略图在后台加载并缓存到磁盘；文件被移动或重命名后仍保留在「最近打开」/「收藏夹」中，书签和阅读位置也一并保留；被删除或移到废纸篓的文件会自动从中移除。
- **原创应用图标**：一张折角的页面，沿对角线依次呈现日间 → 纸质 → 夜间，由 `scripts/make_app_icon.swift` 用代码绘制。

## 📦 安装

从 [Releases](https://github.com/InkCitrus/Expert-PDF-Reader/releases) 下载 `Expert-PDF-Reader-<version>.dmg`，打开后将 **Expert PDF Reader** 拖到**应用程序**文件夹。需要 macOS 14 或更高版本（Apple 芯片或 Intel 均可）。

发布版本尚未经过 Apple 公证，因此 macOS 会阻止首次启动。请打开**系统设置 › 隐私与安全性**，点按**仍要打开**；或者运行：

```zsh
xattr -dr com.apple.quarantine "/Applications/Expert PDF Reader.app"
```

## 🛠 构建与运行

需要 Xcode 命令行工具（`xcode-select --install`）。在仓库根目录下运行：

```zsh
./build.sh && open "build/Expert PDF Reader.app"
```

`build.sh` 默认使用 `xcrun` 选定的 macOS SDK 构建。macOS 27 SDK 中的 SwiftUI 需要编译器插件 SwiftUIMacros，该插件随 Xcode 提供，命令行工具中并不包含；因此没有 Xcode 时，`build.sh` 会改用已安装的最新可用 SDK，并显示所用的 SDK。如需自行指定 SDK，请设置 `SDK_PATH`：

```zsh
SDK_PATH=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk ./build.sh
```

构建通用（Apple 芯片 + Intel）版本，并打包为 `.dmg`：

```zsh
ARCHS="arm64 x86_64" ./build.sh && ./scripts/make_dmg.sh
```

发布新版本有三种方式：推送一个 `v*` 标签（`git tag v0.1.0 && git push origin v0.1.0`）；在 GitHub 上用新的 `v*` 标签发布 Release；或在 Actions 页面填入版本号，运行 **Release** 工作流。随后 `.github/workflows/release.yml` 会构建 `.dmg` 并附加到对应的 GitHub Release。此外，每个 Pull Request 以及每次推送到 `main` 时，CI 都会构建一个 `.dmg` 并保存为产物。

修改图标设计后，重新生成应用图标（`Assets/AppIcon.icns` + `Assets/AppIcon.png`）：

```zsh
swift scripts/make_app_icon.swift
```
