# Expert PDF Reader

[English](../README.md) · [简体中文](README.zh-CN.md) · **繁體中文** · [日本語](README.ja.md) · [한국어](README.ko.md)

一款專注閱讀的 macOS 原生 PDF 閱讀器：多標籤、分割視圖，以及由 GPU 渲染的日間 / 紙質 / 夜間頁面主題。介面設計參考了 PDF Expert 3，但不含編輯、註解與訂閱。

---

## ✨ 功能特色

- **閱讀主題**
  - **日間**：原始色彩，畫布背景為 `#DCDCDE` / `#131314`。
  - **紙質**：暖色紙張 `#F5EFDC`，墨跡 `#3F2A18`，畫布背景 `#E5DECF`；彩色內容保留色相，圖表與標示依然分得清。
  - **夜間**：只反轉亮度、保留色相的柔和反色（$`L' = 0.75(1 - L)`$），紙張 `#000000`、墨跡 `#BFBFBF`，在暗處閱讀也不刺眼，彩色圖表依然可辨；畫布背景 `#202223`。
  - **跟隨系統**：依系統外觀在日間與夜間之間切換，也可以設定成淺色時以紙質代替日間。
  - 任何縮放比例下頁面都保持清晰：色彩矩陣套用在 `NSClipView` 的放大變換之上，因此 PDFKit 的圖塊會以完整的 Retina 解析度渲染。
- **12 種語言**：**简体中文**、**繁體中文**、**English**、**日本語**、**한국어**、**Français**、**Deutsch**、**Español**、**Italiano**、**Português**、**Русский** 與 **Українська**，也可以選擇「跟隨系統」；可在「設定」（`⌘,`）或「顯示方式」選單中即時切換。內建的「閱讀指南」PDF 也已在地化。
- **介面**
  - **一體化 40pt 標題列**：視窗紅綠燈按鈕在標籤列中垂直置中；僅顯示圖示的首頁標籤、文件標籤（游標停留時顯示關閉按鈕，支援右鍵選單），以及用來開啟檔案的 `+` 按鈕。
  - **工具列**：「文件概要」「頁面概覽」「顯示選項」切換按鈕，附預設比例與 `−` / `+` 按鈕的縮放彈出式選單，主題切換器，清除留白、旋轉、分享、書籤按鈕，以及搜尋欄位。
  - **左側面板（240pt）**：在「縮圖」「大綱」（標示目前閱讀的章節）「書籤」之間切換，或顯示「顯示選項」面板（頁面佈局、分割視圖、閱讀主題、清除留白、旋轉、介面外觀）。
  - **右側搜尋結果面板**、右下角**頁碼指示器**（點一下或按 `⌥⌘G` 即可「前往頁碼」），以及**頁面概覽**網格（`⌃⌘1`）。
  - 標籤列、工具列與面板會依**跟隨系統 / 淺色 / 深色**外觀切換配色。
- **首頁標籤**：側邊欄包含「首頁」「最近打開」「收藏夾」（以及「打開檔案…」「閱讀指南」「設定」；在任何地方都能用「輔助說明」›「閱讀指南」（`⌘?`）打開指南），還有拖放區、閱讀主題卡片，以及依系統地區格式顯示日期的文件網格。
- **分頁與多視窗**：
  - **類似瀏覽器的多視窗體驗**：向下拖曳分頁即可分離為獨立視窗；將分頁拖曳至其他視窗的分頁列即可合併，或選擇「視窗」›「合併所有視窗」。
  - **Dock 列與新增視窗（`⌘N`）**：右鍵點按 Dock 列圖示可選擇「新增視窗」「打開…」與「打開最近使用的檔案」。
  - **靈活的分頁管理**：左右拖曳分頁調整順序；懸停顯示完整檔案名稱與檔案夾路徑卡片；開啟兩個以上文件時可展開「所有分頁」選單（`⌄`）；同名檔案自動顯示上層檔案夾名稱進行區分。
  - **快捷鍵切換**：按 `⌃⇥` / `⌃⇧⇥`（或 `⌥⌘←` / `⌥⌘→`、`⇧⌘]` / `⇧⌘[`、`⌃PageUp` / `⌃PageDown`）快速切換分頁；按 `⌃1…9` 或 `⌥⌘1…9` 直接跳轉至第 1…8 個分頁或最後一個分頁（9）；`⇧⌘T` 可原位恢復最近關閉的分頁（最多 25 個），保留原位置與閱讀進度。
  - **指揮中心（Mission Control）**：視窗標題與代表檔案圖示即時同步目前閱讀的檔案名稱，在指揮中心、App Exposé、幕前調度與 Dock 中清晰可見。
  - **分割視圖**：「垂直分割（左右）」或「水平分割（上下）」，支援「對調位置」與「同步捲動與縮放」，也能在首頁標籤中挑選要對照的第二份文件。
- **閱讀**
  - 「單頁」`⌘1`、「雙頁」`⌘2`、「雙頁（首屏單頁顯示）」`⌘3`，跨頁的兩頁在書脊處貼合。右側裝訂的書會自動辨識（依據 PDF 的宣告，或直排頁面上頁碼的位置）並從右往左翻頁；可在「顯示方式」›「翻頁方向」中手動更改。
  - **書本頁碼**：頁碼指示器和「前往頁碼」使用書上印的頁碼（PDF 內建的頁碼缺漏或有誤時，從頁面上辨識），雙頁時顯示跨頁的兩個頁碼。可辨識前言的羅馬數字頁碼與正文的阿拉伯數字頁碼，目錄與縮圖也顯示相同的頁碼；在「前往頁碼」中輸入 `(n)` 可跳至檔案的第 n 頁。
  - **`←` / `→`**：在目前聚焦的窗格中翻頁。
  - **清除留白（`⇧⌘M`）**：偵測每頁的內容邊界並裁切頁邊距，計算在背景完成。
  - **左側面板（`⌘B`）**：套用主題的頁面縮圖、文件大綱與書籤（`⌘D`）。
  - **全文搜尋（`⌘F`）**：在背景執行，邊搜尋邊依頁列出結果，並醒目標示上下文。
  - **從上次停下的地方繼續**：每份文件重新開啟時都會回到上次的頁碼、縮放比例與版面配置，啟動時也會還原上次工作階段的標籤頁。
  - **受密碼保護的 PDF** 會要求輸入密碼；無法開啟的檔案會說明原因。
  - 可以把 PDF 拖放到視窗任何位置或 Dock 上的圖示來開啟；除了 `⌘+`，`⌘=` 也能放大。
- **更快的首頁標籤**：「最近打開」最多保留 50 份文件（最近 10 份也會列在「檔案」›「打開最近使用的檔案」中）；封面縮圖在背景載入並快取到磁碟；檔案被移動或重新命名後，仍會留在「最近打開」/「收藏夾」中，書籤與閱讀位置也一併保留；被刪除或移到垃圾桶的檔案會自動從中移除。
- **原創 App 圖示**：一張折角的頁面，沿對角線依序呈現日間 → 紙質 → 夜間，由 `scripts/make_app_icon.swift` 以程式碼繪製。

## 📦 安裝

從 [Releases](https://github.com/InkCitrus/Expert-PDF-Reader/releases) 下載 `Expert-PDF-Reader-<version>.dmg`，打開後將 **Expert PDF Reader** 拖到**應用程式**檔案夾。需要 macOS 14 或以上版本（Apple 晶片或 Intel 皆可）。

發佈的版本尚未經過 Apple 公證，因此 macOS 會阻擋第一次啟動。請打開**系統設定 › 隱私權與安全性**，按一下**強制打開**；或執行：

```zsh
xattr -dr com.apple.quarantine "/Applications/Expert PDF Reader.app"
```

## 🛠 建置與執行

需要 Xcode 命令列工具（`xcode-select --install`）。在儲存庫根目錄下執行：

```zsh
./build.sh && open "build/Expert PDF Reader.app"
```

`build.sh` 預設使用 `xcrun` 選定的 macOS SDK 建置。macOS 27 SDK 中的 SwiftUI 需要編譯器外掛 SwiftUIMacros，此外掛隨 Xcode 提供，命令列工具中並未包含；因此沒有 Xcode 時，`build.sh` 會改用已安裝的最新可用 SDK，並顯示所用的 SDK。如需自行指定 SDK，請設定 `SDK_PATH`：

```zsh
SDK_PATH=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk ./build.sh
```

建置通用（Apple 晶片 + Intel）版本，並封裝成 `.dmg`：

```zsh
ARCHS="arm64 x86_64" ./build.sh && ./scripts/make_dmg.sh
```

發佈新版本有三種方式：推送一個 `v*` 標籤（`git tag v0.1.0 && git push origin v0.1.0`）；在 GitHub 上以新的 `v*` 標籤發佈 Release；或在 Actions 頁面填入版本號，執行 **Release** 工作流程。接著 `.github/workflows/release.yml` 會建置 `.dmg` 並附加到對應的 GitHub Release。此外，每個 Pull Request 以及每次推送到 `main` 時，CI 都會建置一個 `.dmg` 並保存為產出物。

修改圖示設計後，重新產生 App 圖示（`Assets/AppIcon.icns` + `Assets/AppIcon.png`）：

```zsh
swift scripts/make_app_icon.swift
```
